# montanarograziano.github.io

Source for [Graziano Montanaro's portfolio](https://montanarograziano.github.io), a static Astro site with a resume, skills, projects, and publications.

## Stack

- [Astro](https://astro.build/) (static output)
- Deployed to GitHub Pages via [withastro/action](https://github.com/withastro/action) on every push to `master`

## Local development

```bash
npm install
npm run dev       # start dev server
npm run build     # build to dist/
npm run preview   # preview the production build
```
